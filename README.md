# Тень: Последний миллион

Семейная детективная игра на 3–6 игроков. Телефон — ведущий: ведёт раунды и таймер, тайно раздаёт
роли, считает деньги и подводит итог. Играют вживую: прячут записки по квартире, торгуются, блефуют.

**Играть:** https://aipanov.github.io/ten/

- iPhone: откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
- Android: откройте в Chrome → ⋮ → «Установить приложение».
- Одним файлом без интернета: [ten.html](ten.html) — скачать и открыть в браузере.

После первого открытия игра работает без интернета. Нужны деньги «Монополии», кубик, ручка и бумага.
